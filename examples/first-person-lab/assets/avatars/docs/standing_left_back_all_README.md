# Starlit Cinema Avatar Turnaround — Left + Back

Nine original-style avatars, two still views each (18 original PNGs).

- `left_side.png`: established left-facing profile
- `back.png`: standing rear view
- `preview_all_pairs.jpg`: overview to review pairings
- `manifest.json`: filename and source metadata

**These PNGs are byte-for-byte copies of the earlier generated individual stills.** No artwork was regenerated or modified, and no new clipping, cleanup, or alpha extraction was applied. The images have RGBA transparency as supplied.

The later, unrelated human-character lineup artwork is intentionally excluded. The incorrectly generated right-side views are also excluded.
